Active Mathematical & Graph Algorithms
1. Minimum-Cost Maximum-Flow (MCMF) Network Simplex
Optimizes system-wide parking allocation by modeling users as source flow, road impedances as edge costs, and facility slots as bounded sinks.
2. Dijkstra's Algorithm Exact Shortest Path
Computes guaranteed shortest road distance path from driver origin to assigned facility entry node.
3. A* Search Algorithm Haversine Heuristic
Accelerates shortest-path computation with admissible straight-line distance heuristic for rapid in-vehicle navigation.
4. First-Come-First-Served (FCFS) Baseline Benchmark
Traditional uncoordinated parking baseline for mathematical benchmarking against MCMF optimization.
